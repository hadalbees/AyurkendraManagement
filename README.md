# AHMS – Advanced Hospital Management System

## Tech Stack
- Django 5.x
- PostgreSQL
- HTML, CSS, JavaScript

## Setup
1. Clone repo
2. Create virtual environment
3. Install dependencies
4. Create .env file
5. Run migrations
6. Run server
